# EXPANDING_RISK_FORECAST_30_70

[← 전체 전략](../strategy.md)

## 목적과 상태

향후 하락 여부를 이진 분류하지 않고, 다음 21거래일의 위험 크기를 연속값으로 예측해
QQQ 목표 비중을 조절하는 전략입니다. 별도의 `BULL`·`BEAR` 상태는 사용하지 않습니다.

`BaseStrategy`의 공통 실행 형식 위에 확장학습 회귀, 30~70% 연속 위험 목표와 월간
5%p 밴드를 새로 구현했습니다. 고정 규칙 대신 당시까지 확정된 데이터로 위험 강도를
추정하려는 목적입니다. 미래 정보 누수를 피하는 대신 60개월 워밍업과 추정 오차가
발생하며, 모델 반응이 늦거나 기대수익을 과도하게 줄일 수 있습니다.

개발 구간에서는 static 7:3보다 CAGR, MDD와 Sharpe가 개선됐지만 2018년 이후 검증과
잠금 구간에서는 MDD 개선에 비해 CAGR과 Sharpe의 손실이 컸습니다. 따라서 이 전략은
검증 완료 전략이 아니라 활성 목록에서 추가 관찰하는 연구 전략입니다.

## 자산과 목표 비중

필요 ticker는 `QQQ`, `BND`, `BIL`입니다.

| 자산 | 역할 | 목표 범위 |
|---|---|---:|
| QQQ | 위험자산 | 30~70% |
| BND | 안전자산 | QQQ 제외 비중의 50% |
| BIL | 안전자산 | QQQ 제외 비중의 50% |

목표 QQQ 비중은 항상 70% 이하입니다. 다만 월간 5%p 리밸런싱 밴드를 사용하므로 시장가격
변동으로 계산되는 실제 평가비중은 다음 판단 전에 일시적으로 70%를 넘을 수 있습니다.

## 월별 특징

매월 첫 거래일에 다음 값을 사용합니다.

1. QQQ ROC20
2. QQQ ROC60
3. QQQ ROC120
4. QQQ 종가 / EMA200 - 1
5. QQQ 60일 연환산 변동성
6. QQQ 120일 고점 대비 낙폭
7. QQQ 20일 변동성 / 60일 변동성 - 1

현재 월의 특징은 즉시 예측에 사용하지만 학습에는 넣지 않습니다. 해당 시점 이후 21거래일이
완전히 지난 뒤에만 목표값과 함께 학습 집합으로 이동합니다.

## 학습 목표와 회귀

각 월별 관측치에서 다음 두 값을 계산합니다.

```text
하방변동성 = sqrt(mean(min(일수익률, 0)^2) × 252)
최대 경로손실 = max(0, 1 - 향후 21일 최저가격 / 현재가격)
```

각 목표는 표준화된 특징을 사용하는 ridge 회귀로 별도 예측합니다. 절편은 규제하지 않고
특징 계수에 5.0의 L2 패널티를 적용합니다. 60개월부터 모델을 활성화하며 120개월까지는
예측을 학습 표본의 평균으로 축소합니다.

```text
신뢰도 = min(1, 학습 표본 수 / 120)
축소 예측 = 과거 평균 + 신뢰도 × (회귀 예측 - 과거 평균)

변동성 비율 = 축소 하방변동성 예측 / 과거 평균 하방변동성
손실 비율 = 축소 최대손실 예측 / 과거 평균 최대손실
stress = clip((변동성 비율 + 손실 비율) / 2, 0.5, 3.0)
```

## QQQ 목표 비중

stress가 1.10 이하이면 QQQ 70%를 유지합니다. 1.10에서 1.50 사이에서는 선형으로
축소하며 1.50 이상이면 QQQ 30%를 목표로 합니다.

```text
reduction = clip((stress - 1.10) / (1.50 - 1.10), 0, 1)
QQQ 목표 = 70% - 40% × reduction
```

## 리밸런싱

```text
최초 평가
└── 현재 모델 목표로 3거래일 분할 리밸런싱

매월 첫 거래일
└── 확정된 21일 목표를 학습 집합에 추가
    └── 새 위험 예측과 목표 비중 계산
        ├── 어느 자산이든 현재 비중과 목표의 차이가 5%p 이상
        │   └── 3거래일 분할 리밸런싱
        └── 그 미만이면 보유
```

## 워밍업과 재현성

전략 객체는 백테스트 또는 애플리케이션 실행 시점부터 관측치를 축적합니다. `data/`와
`START_DATE`가 2012년부터라면 약 60개월 동안 70/30 목표를 유지한 뒤 모델이 활성화됩니다.
장기 프록시 데이터로 먼저 학습한 검증 모듈과는 활성 시작일이 다를 수 있습니다.

현재 `data/`와 `main.py` 조건의 2012-01-03~2026-07-31 온라인 실행 결과는 CAGR
12.67%, MDD -22.33%, Sharpe 0.786입니다. 이 수치는 실행 시작 후 새로 워밍업한
회고적 백테스트 결과이며 장기 프록시 검증 결과나 미래 성과를 의미하지 않습니다.

연구 재현용 구현과 결과 파일은 `src/validation/continuous_risk_forecast.py` 및
`results/continuous_risk_forecast_*.csv`에 있습니다.
