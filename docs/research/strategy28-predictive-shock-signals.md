# 28번 전략: 금융주 선행 약세와 단기 충격 신호 검증

## 결론

금융주(XLF)의 S&P 500(SPY) 대비 약세와 신용 스프레드 확대를 함께 보는 보조 경보는 **2007~09 금융위기 방어에는 도움**이 됐다. 그러나 닷컴 버블에는 경보가 한 번도 발생하지 않았고, 2020년에는 반등을 놓쳐 최근 구간 연복리 수익률을 낮췄다. 따라서 28번 전략에 즉시 채택할 근거는 부족하다. 변동성 정규화 단기 충격 경보는 거래와 재진입 손실이 많아 기각한다. 기존 28번 YAML과 배포 설정은 변경하지 않았다.

## 실험 설계

- 기준: 기존 28번에 연구용 상대약세·신용경보 65% 상한, 닷컴 2차 방어 20% 상한을 덧씌운 `REL10_CAP20_INDEPENDENT`. **원래 28번 단독과 혼동하면 안 된다.**
- 금융주 경보: 최근 20거래일 `XLF/SPY` 수익률 ≤ -8%, `BAA10Y` ≥ 1.8%p, 20거래일 증가폭 ≥ 0.2%p. 발동 시 QQQ 상한 35%, 나머지 BIL. 해제는 XLF/SPY 20일 상대수익률 > -2%, BAA10Y 20일 변화 ≤ 0, SPY > EMA55가 5거래일 연속일 때. 기존 오버레이의 상한과는 더 낮은 상한을 적용한다.
- 단기 충격 경보: QQQ 5거래일 수익률을 **전일까지의** 60거래일 5일 수익률 표준편차로 나눈 값 ≤ -2.5, 동시에 VIX 5일 상승률 ≥ 30% 또는 BAA10Y 5일 증가폭 ≥ 0.2%p. 발동 시 QQQ 상한 35%; QQQ > EMA55와 VIX < 30이 10거래일 연속이면 해제.
- 신호는 당일 종가로 평가하고 리밸런싱은 다음 거래일 시가에 실행. 거래비용은 프로젝트 기본값. 3배 비용, 경보 진입 2·5거래일 지연을 추가 테스트했다. 지연 시험은 첫 신호를 기록한 뒤 그 날짜만 늦추며, 그 사이 신호가 사라져도 예약 경보를 실행한다.
- 기간: 최근 2012-01-03~2026-07-31; 닷컴 2000-03-10~2005-12-30; 금융위기 2007-01-03~2011-12-30. 닷컴·금융위기는 기존 연구와 동일한 사후 작성된 CAPE 대용 파라미터와 BIL 대용 현금 데이터를 사용한다. 실제 당시 운용 가능한 성과로 해석하면 안 된다.

| 구간 | 기준 CAGR / MDD | 금융주 경보 CAGR / MDD | 단기 충격 CAGR / MDD | 결합 CAGR / MDD |
| --- | ---: | ---: | ---: | ---: |
| 최근 | 21.18% / -16.25% | 20.14% / -16.25% | 17.08% / -18.39% | 16.91% / -18.39% |
| 닷컴 대용 | 2.92% / -23.00% | 2.92% / -23.00% | 1.99% / -23.00% | 1.99% / -23.00% |
| 금융위기 대용 | 11.69% / -26.74% | 13.07% / -17.19% | 8.10% / -25.36% | 10.22% / -17.19% |

금융주 경보는 금융위기 구간에서 2007-11-08 켜져 2008-04-30 꺼졌고, 2008-07-09 다시 켜져 2009-04-21 꺼졌다. 중간 반등에 재진입했지만, 이후 재하락 전에 재경보가 발생해 이 구간에서는 방어 효과가 유지됐다. 최근에는 2020-03-09~2020-06-01, 2023-03-13~2023-04-20 두 번 켜졌다. 특히 코로나 구간의 기초 오버레이 수익률 37.92%가 금융주 경보에서는 24.32%로 낮아졌다. MDD 개선은 없었다. 닷컴 구간에서는 금융주 신호가 발생하지 않아 방어 효과가 전혀 추가되지 않았다.

## 지연·비용 스트레스 테스트

| 금융주 경보 변형 | 최근 CAGR / MDD | 금융위기 대용 CAGR / MDD |
| --- | ---: | ---: |
| 즉시, 기본 비용 | 20.14% / -16.25% | 13.07% / -17.19% |
| 2거래일 진입 지연 | 20.17% / -16.25% | 12.70% / -18.54% |
| 5거래일 진입 지연 | 20.26% / -16.25% | 12.97% / -17.58% |
| 즉시, 거래비용 3배 | 19.97% / -16.37% | 12.90% / -17.57% |

이 지연·비용 조건에서도 금융위기 구간의 이득은 남았지만, 다른 역사적 위기에서 일반화된다고 볼 수는 없다. 특히 2일보다 5일 지연 결과가 좋은 것은 경보가 일찍 울릴수록 언제나 유리하지 않음을 보여준다. 금융주 경보의 2008년 두 차례 발동, 2020년 반등 손실은 해제·재진입 설계를 더 검토해야 한다는 근거다. 단기 충격 신호는 최근 16회 발동했고 최근 CAGR과 MDD가 모두 악화되어 이 실험 조건에서는 배제한다.

## 해석상 한계와 다음 검증

이것은 2008년 사례에 맞춰 제안한 조건의 **탐색적 백테스트**다. 숫자와 해제 조건을 사전에 고정한 독립 표본이 없고, 두 가지 역사적 대형 하락만으로 통계적 신뢰도를 평가할 수 없다. 금융업종이 주도하지 않는 닷컴형 하락에는 반응하지 않으며, 금융주 약세가 일시적일 때는 2020년처럼 수익률을 잠식할 수 있다. 따라서 별도 금융위기 전용 경보로 관찰하되 현재 전략은 유지하는 편이 타당하다. 후속 실험은 코로나형 급락을 피하기 위한 신호의 **지속성 조건**과 해제·재진입 조건을 사전에 정해, 2020년뿐 아니라 2008년과 2023년에 동시에 확인하는 것이다.

재현: `python src/legacy-python/validation/strategy28_predictive_shock.py`. 연구 입력 `tmp/XLF.csv`는 Yahoo Finance에서 `auto_adjust=True`로 받은 XLF OHLC, `tmp/BAA10Y.csv`는 기존 연구의 FRED 자료다. 원자료와 결과 CSV는 저장소에 추가하지 않는다. 결과는 `results/strategy28_predictive_shock_{summary,events,transitions}.csv`에 생성된다. XLF는 [State Street의 공식 상품 페이지](https://www.ssga.com/us/en/intermediary/etfs/state-street-financial-select-sector-spdr-etf-xlf)에 따르면 1998년 12월 설정되어 닷컴 기간 비교에 사용할 수 있다. 신용 스프레드의 경기침체 경보 해석에는 [연방준비제도 연구](https://www.federalreserve.gov/econres/notes/feds-notes/updating-the-recession-risk-and-the-excess-bond-premium-20161006.html)를 참고했지만, 이 실험은 그 연구의 EBP 대신 BAA10Y를 사용한다.
