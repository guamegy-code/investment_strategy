# 30번 후보: 두 단계 가격 급락 경보 검증

검증일: 2026-09-27. 기준은 28번에 상대약세·신용 경보 65%/20% 상한과 독립 해제를 섞은 연구안(`REL10_CAP20_INDEPENDENT`)이다. 신용 관측은 1거래일 늦춰 사용한다. 30번 운영 YAML은 아직 만들지 않았다.

## 가설과 구현

기존 혼합안은 신용 악화가 없는 빠른 동반 급락에서 추가 경보가 켜지지 않았다. 가격만으로 작동하는 작은 초기 경보를 두고, 하락이 이어지면 방어를 강화하면 가상 급락 MDD를 줄이면서 평상시 비용도 낮출 수 있다는 가설을 시험했다. 기존 28번 목표가 경보 상한보다 낮을 때는 28번 목표를 우선한다. 당일 종가 신호, 다음 거래일 시가 집행이다.

| 프로필 | 첫 경보 | 심화 경보 | QQQ 상한 | 해제 |
| --- | --- | --- | --- | --- |
| 빠른 65→35 | QQQ 3일 ≤ -7% 및 SPY 3일 ≤ -4% | QQQ 5일 ≤ -12% 및 SPY 5일 ≤ -7% | 65% → 35% | QQQ·SPY가 EMA20 위이고 5일 수익률 양수인 상태 3일이면 35→65, 다시 3일 회복이면 해제 |
| 빠른 70→50 | 동일 | 동일 | 70% → 50% | 동일 |
| 느린 65→35 | QQQ 5일 ≤ -10% 및 SPY 5일 ≤ -6% | 동일 | 65% → 35% | 동일 |

해제 뒤에는 20거래일 재발동 제한을 적용했다. 추가로 빠른 두 프로필에 (a) 경보 5거래일 전 QQQ의 20일 고점 대비 낙폭이 -5%보다 작을 것, (b) 심화되지 않은 첫 경보를 5거래일 뒤 해제할 것을 각각 순차 시험했다. 이는 기존 한 번에 35%로 낮추는 급락 경보와 분리한 **연구용 후보값**이지 검증된 최적값이 아니다.

## 가상 급락 방어

2024년 실제 조정가격에 사전 지정한 급락 배율을 곱하고 기술지표를 전부 재계산했다. 신용스프레드 가상 변화는 1거래일 늦게 반영했다. 사건 기간 MDD:

| 경로 | 기존 혼합안 | 빠른 65→35 | 빠른 70→50 | 느린 65→35 |
| --- | ---: | ---: | ---: | ---: |
| 10일 동반 급락·신용 무반응 | -39.3% | **-22.6%** | -26.4% | -23.9% |
| QQQ 급락·신용 확대 지연 | -37.6% | **-23.4%** | -27.0% | -24.4% |
| 빠른 V자 회복 | -23.2% | -20.3% | -20.7% | -21.9% |

빠른 첫 경보는 신용 무반응 경로에서 사건 시작 대비 약 -5.0% 손실이 난 날(2024-01-03)에 켜졌다. 기존 한 번에 35%로 줄이는 5일 경보는 약 -13.3% 손실 뒤 켜졌다. 따라서 단계적 경보의 **발동 속도**가 가상 MDD를 추가로 낮췄다. 안정 구간 조건을 붙여도 이 경로의 발동일과 MDD는 같았다. 반등 뒤 재하락 경로에서는 이미 원래 혼합안의 신용·상대약세 방어가 켜져 별도 가격 경보의 추가 효과가 거의 없었다.

## 과거 구간의 비용

| 프로필 | 2012~2026 CAGR / MDD | 닷컴 대체검증 CAGR / MDD | 금융위기 대체검증 CAGR / MDD |
| --- | ---: | ---: | ---: |
| 기존 혼합안 | **21.188% / -16.253%** | 2.892% / -23.100% | 11.692% / -26.745% |
| 빠른 65→35 | 20.040% / -16.429% | 2.953% / -22.838% | 10.907% / -25.474% |
| 빠른 70→50 | 20.280% / -16.214% | 2.953% / -22.838% | 11.122% / -25.638% |
| 느린 65→35 | 20.409% / -16.323% | 3.015% / -22.567% | 10.530% / -26.727% |
| 안정 구간 조건 + 빠른 65→35 | 20.228% / -16.429% | 2.899% / -23.139% | 10.874% / -25.582% |
| 안정 구간 조건 + 빠른 70→50 | 20.437% / -16.253% | 2.899% / -23.139% | 11.089% / -25.745% |
| 위 조건 + 첫 경보 5일 제한, 65→35 | 20.324% / -16.602% | 2.922% / -23.114% | 10.660% / -27.051% |
| 위 조건 + 첫 경보 5일 제한, 70→50 | 20.519% / -16.253% | 2.922% / -23.114% | 10.904% / -27.007% |

안정 구간 조건은 실제 2024-08-05 경보를 걸러냈고 가상 2024-01-03 급락 경보는 유지했다. 그러나 2015-08-21, 2020-02-25, 2020-09-08 등 다른 초기 경보는 남았다. 5일 제한을 붙이면 최근 수익률 손실이 조금 줄지만 금융위기에서는 너무 빨리 비중을 복귀시켜 MDD가 기존 혼합안보다 커진다. 이 실험의 모든 프로필은 2012~2026 CAGR 21.188%에 미치지 못한다. 28번 단독의 같은 구간 21.135%에도 못 미친다.

## 판단

두 단계 가격 경보는 신용 지표와 무관한 가상 급락에 더 빨리 반응한다. 반면 실제 구간에서는 여러 번 켜진 뒤 비중을 줄였다가 복귀하면서 수익률을 상당히 잃는다. 첫 상한 완화, 직전 안정 조건, 5일 만료를 차례로 더해도 **가상 급락 방어와 기존 수익률 보존을 동시에 만족하지 못했다**. 현재 숫자를 30번 전략에 넣는 것은 권하지 않는다. 더 많은 임계값을 훑어 같은 데이터에 맞추는 것도 신뢰도를 높이지 않는다.

가격 급락이 발생한 첫 거래일의 손실은 종가 신호로 피할 수 없다. 이 경보를 실제로 도입하려면 평상시 수익률을 얼마까지 희생할 수 있는지 먼저 정해야 한다. [AQR의 위험 완화 연구](https://www.aqr.com/-/media/AQR/Documents/Alternative-Thinking/AQR-Alternative-Thinking---Key-Design-Choices-when-Building-a-Risk-Mitigating-Portfolio.pdf?hash=43D2CF59742FB29906A368F8AE472831&sc_lang=en)도 짧은 가격 신호가 잦은 방향 전환에 취약할 수 있다고 설명한다. 이 연구가 여기의 특정 문턱값을 입증하는 것은 아니다.
