# 퇴직연금 31·31P: 제한 재진입만 채택

개인연금 33번의 두 개선을 31번의 70/30 구조에 옮겨 비교했다.
**제한 재진입만 version 3에 반영한다. 회복 확인 가속은 채택하지 않는다.**
31P는 동일한 상품 매핑을 유지하고 31번 version 3의 신호를 따른다.

## 고정된 적용 규칙

주 첫 거래일에 QQQ 종가가 EMA20 위이고 5일 수익률이 양수이면,
기존 목표에서 70%까지 남은 QQQ 비중의 절반을 BIL에서 옮긴다.
WARNING의 50/30/20은 60/30/10, RECOVERY의 60/30/10은 65/30/5가 된다.
순서는 QQQ/TDF/BIL이다. TDF 목표는 그대로 유지하고 QQQ 목표는 70%를 넘지 않는다.

BEAR·DEFENSE·신용·심화·구조적 방어에서는 추가하지 않는다. 가격 회복 조건이
깨지거나 방어가 켜지면 매일 종료한다. 심화 방어 중 실제 보유량 기준 재매수 제한,
밸류에이션 고점 기억, 기존 매도 확인 기간을 보존한다. 복귀도 원래 3일을 확인한다.
재진입 활성화 중 목표 변경, 시작·종료 및 기존 비중 괴리 기준으로 리밸런싱한다.

## 비교 결과

2012-01-03~2026-07-31, 기존 로컬 QQQ·BIL·TDF 대체지수,
수수료 0.015%·슬리피지 0.020%, 다음 시가 실행, 실제 변경 보유량 피드백이다.
기준은 Git `d5b3ac1`의 31번 version 2다.

채택안은 79일 활성화되었다. 닷컴(2000-03-10~2005-12-30)과
금융위기(2007-01-03~2011-12-30)는 TDF 해외주식을 SPY/QQQ로 각각 대체한
네 경로에서 추가 재진입이 발생하지 않아 기존 경로와 같았다.
대체자료에는 CAPE·현금·채권 합성자료도 포함되므로 실제 TDF/국내 ETF 성과가 아니다.

개인연금의 우수한 조합을 퇴직연금에 그대로 옮기면 수익 개선이 보장되지 않았다.
회복 가속 포함 조합은 체결 지연 시 MDD도 -20.9426%로 나빠졌다.
기간·임계값을 추가 탐색하지 않고 두 구성요소를 분리해 비교했다.
채택안의 CAGR 차이는 약 0.057%p로 작고, 거래 증가 및 과거 자료 재사용의 한계가 있다.

## 검증·운영

3조합 × 8조건 × 기준/후보 = 48회 비교. 독립 정책 구현과 운영 YAML의 일별 목표,
보호 상태, 매매 신호를 대조하고 QQQ 목표 상한 및 TDF 목표 보존을 확인했다.
채택안 5개 기본 경로 총 9,107거래일은 브라우저·Worker와도 비교했다.
31P의 상품별 목표 매핑은 별도 합성자료로 검증했다.

```powershell
$env:PYTHONPATH = Join-Path (Get-Location) 'src/legacy-python'
.venv/Scripts/python.exe src/legacy-python/validation/strategy31_reentry_review.py
.venv/Scripts/python.exe src/legacy-python/validation/strategy31_reentry_review.py --buy-only
.venv/Scripts/python.exe src/legacy-python/validation/strategy31_reentry_review.py --reentry-only
node tests/web/strategy33_parity.mjs --retirement
```

결과는 Git 제외 경로 `results/research/qqq/strategy31_reentry/`에 저장한다.
기존 31·31P 알림 사용자는 전략 변경 후 Apps Script의
`initializeNotificationStates()`로 상태를 다시 초기화해야 전체 과거 재계산과 일치한다.
