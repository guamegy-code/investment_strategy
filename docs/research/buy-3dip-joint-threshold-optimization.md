# Buy 3 Dip 진입·회복 시점 공동 최적화

## 목적

20번 전략의 QQQ 목표 비중(70% / 87% / 90% / 100%)은 유지하면서, 하락 진입점과
상승 시 한 단계씩 현금화하는 회복 시점을 함께 탐색했다. 회복 매도는 항상 해당
진입점보다 높은 가격에서만 발생하도록 해 단계별 히스테리시스를 유지했다.

## 검증 조건

- 전체 기간: 2012-01-03~2026-08-14
- 자산: QQQ, BIL
- 수수료 0.015%, 슬리피지 0.020%, 신호 다음 거래일 시가 체결
- stage 0~3, QQQ 70% / 87% / 90% / 100% 고정
- 각 후보는 `b < c < d`, `stage 3 → 2` 회복점이 c보다 높고,
  `stage 2 → 1` 회복점이 b보다 높도록 제한

## 결과

| 구분 | 진입 b / c / d | 회복 stage 1→0 / 2→1 / 3→2 | CAGR | MDD | Calmar |
|---|---:|---:|---:|---:|---:|
| 기존 20번 v1 | -10% / -18% / -32% | 0% / -10% / -18% | 17.515% | -28.862% | 0.607 |
| 채택 21번 v1 | -10% / -20% / -32.5% | +7.5% / -8.5% / -17.5% | **18.031%** | **-28.612%** | **0.630** |

21번은 기존 20번 대비 CAGR을 0.516%p 높이고 MDD를 0.251%p 낮췄다. 최종 자산은
10.573에서 11.273으로 증가했다. 개발 구간 CAGR은 18.328%로 기존 18.387%보다
낮지만 MDD는 -23.472%로 개선됐다. 최근 구간 CAGR은 17.702%로 기존 16.417%보다
높고 MDD도 -28.612%로 개선됐다.

탐색 결과 회복 시점 `-17.5%`, `-8.5%`, `+7.5%`는 각각 기존보다 QQQ 고비중을
더 오래 유지한다. stage 1이 전고점보다 7.5% 높은 지점에서 stage 0으로 복귀하므로,
그 시점의 가격이 이후 stage 0의 새 기준점이 된다.

## 검증

격자 탐색 결과는 실제 DSL 엔진에서도 CAGR 18.031%, MDD -28.612%, Calmar 0.630으로
동일하게 재현됐다. 전략 20은 변경하지 않고 21번을 별도 전략으로 생성했으며 Cloudflare에는 배포하지
않았다.
