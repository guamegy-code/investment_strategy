# Buy 3 Dip 분할 현금화 실험

## 목적

21번 전략은 회복 시 각 stage의 QQQ 비중을 한 번에 다음 단계로 낮춘다. 상승 추세
참여율을 높일 수 있는지 확인하기 위해 stage 3, stage 2, stage 1의 현금화를 각각
두 번으로 나누었다. 중간 단계에서 반등이 실패하면 원래 위험 비중으로 되돌아가도록
상태 전환을 구성했다.

## 고정 조건

- 기간: 2012-01-03~2026-08-14
- 21번의 진입·회복 기준: `-10% / -20% / -32.5%`, `+7.5% / -8.5% / -17.5%`
- 기본 QQQ 비중: stage 0~3에서 `70% / 87% / 90% / 100%`
- 수수료 0.015%, 슬리피지 0.020%, 신호 다음 거래일 시가 체결

## 결과

| 분할 대상 | 가장 높은 CAGR 후보 | CAGR | MDD | Calmar | 21번 대비 판단 |
|---|---|---:|---:|---:|---|
| 없음 (21번) | - | 18.031% | -28.612% | **0.630** | 기준 |
| stage 3 | 100% → 92% → 90% | 18.007% | -28.939% | 0.622 | CAGR·MDD 모두 악화 |
| stage 2 | 90% → 89% → 87% | 18.032% | -28.839% | 0.625 | CAGR +0.001%p, MDD -0.227%p |
| stage 1 | 87% → 85% → 70% | 17.941% | -28.583% | 0.628 | MDD +0.029%p, CAGR -0.090%p |

stage 3은 첫 회복점 `-17.5%`에서 QQQ 92%로 낮춘 뒤 `-10%`에서 90%로,
stage 2는 `-8%`에서 89%로 낮춘 뒤 전고점에서 87%로, stage 1은 `+10%`에서
85%로 낮춘 뒤 `+20%`에서 70%로 낮추는 조합이 각 탐색군에서 CAGR이 가장 높았다.

## 결론

분할 현금화는 상승 노출을 오래 유지하지만, 이 데이터에서는 추가 전환 거래와
되돌림 구간의 노출 증가를 보상하지 못했다. 21번의 즉시 한 단계 현금화 규칙을
유지하며 전략 정의와 Cloudflare 배포는 변경하지 않는다.
