# 30번 후보: 예상하지 못한 하락 경로 취약점 탐색

검증일: 2026-09-26. 30번 YAML은 아직 만들지 않았다. 비교 대상은 운영 28번, 2012~2026 CAGR 21.182%의 연구용 혼합안(`REL10_CAP20_INDEPENDENT`), 그리고 심화 방어 중 QQQ 재매수를 제한하는 후보안이다. 가상 경로는 미래 예측이나 발생 확률이 아니라 **조건부 취약점 시험**이다.

## 방법

2024-01-02~2024-12-31의 실제 QQQ·SPY 조정가격 OHLC에 사전 지정한 배율 경로를 곱했다. 변형한 가격에서 모든 기술지표와 QQQ/SPY 상대수익률을 다시 계산했다. 신용스프레드는 사건 직전 값에 가상 확대·축소 경로를 더하고 **1거래일 후** 신호에 반영했다. 현금성 BIL과 밸류에이션 점수는 원래 자료로 고정했다. 주문은 종가 신호 다음 거래일 시가에 실행한다. 각 안은 동일한 가상 경로를 사용한다. 따라서 가격·신용·밸류에이션의 경제적 동시 변화를 완벽하게 모사하지 않는다.

가상 경로의 종점은 다음과 같다. 배율 0.60은 실제 해당 일자의 QQQ 가격에 0.60을 곱한다는 뜻이며, 정확히 사건 시작일 대비 -40% 수익률을 의미하지 않는다.

| 경로 | 가격 배율과 신용 변화 | 겨냥한 취약점 |
| --- | --- | --- |
| 빠른 동반 하락·신용 무반응 | 10거래일에 QQQ ×0.60, SPY ×0.65, 신용 확대 없음 | QQQ 상대약세·신용 확인이 모두 실패 |
| 빠른 QQQ 하락·신용 지연 | 12거래일에 QQQ ×0.60, SPY ×0.80; 신용 확대는 15거래일 뒤 시작 | 방어 전 손실과 뒤늦은 매도 |
| 긴 성장주 하락 | 60거래일에 QQQ ×0.70, 160거래일에 ×0.45; SPY와 신용은 더 완만히 악화 | 두 단계 방어와 회복 손실 |
| 반등 뒤 재하락 | QQQ ×0.70 → ×0.90 → ×0.50, 신용도 재악화 | 해제·재진입과 재매수 제한 |
| 빠른 V자 회복 | 15거래일에 QQQ ×0.65, 70거래일에 배율 1.00 회복 | 급락 방어 후 반등을 놓치는지 |

실제 2024년 경로를 그대로 둔 대조군에서는 28번·혼합안·재매수 제한안 모두 사건 기간 MDD -13.56%, 수익률 +27.74%였다.

## 결과: 사건 기간 최대 낙폭

| 경로 | 28번 | 기존 혼합안 | 재매수 제한 | 별도 급락 경보 시험안 |
| --- | ---: | ---: | ---: | ---: |
| 빠른 동반 하락·신용 무반응 | -39.3% | -39.3% | -39.3% | -25.0% |
| 빠른 QQQ 하락·신용 지연 | -37.6% | -37.6% | -37.6% | -26.0% |
| 긴 성장주 하락 | -22.1% | -10.6% | -10.6% | -10.6% |
| 반등 뒤 재하락 | -29.7% | -17.5% | -17.5% | -17.5% |
| 빠른 V자 회복 | -31.2% | -23.2% | -23.2% | -23.2% |

가장 큰 발견은 **경보가 늦으면 심화 방어 중 재매수 제한이 최대 낙폭을 줄이지 못한다**는 것이다. 신용이 늦는 경로에서 혼합안의 첫 단계와 심화 단계는 모두 2024-02-08에 켜졌지만, 그날까지 사건 시작 대비 이미 **-36.8%** 손실이 났다. 신용이 전혀 확대되지 않는 동반 급락 경로에서는 둘 다 켜지지 않았다.

반대로 긴 성장주 하락에서는 첫 경보가 시작 대비 -2.6%, 심화 경보가 -9.1% 수준에서 발생해 사건 MDD를 -22.1%에서 -10.6%로 줄였다. 반등 뒤 재하락 경로에서도 약 -29.7%에서 -17.5%로 줄였다. 즉 혼합안의 방어 능력은 **하락의 종류보다 신호가 하락보다 먼저 나타나는지**에 크게 좌우된다.

## 재매수 제한과 반등 손실

| 경로 | 기존 혼합안 사건 종료 수익률 | 재매수 제한 사건 종료 수익률 | 10% 비중 하한 시험안 |
| --- | ---: | ---: | ---: |
| 빠른 QQQ 하락·신용 지연 | -20.3% | -29.2% | -24.5% |
| 긴 성장주 하락 | +3.0% | -6.1% | -1.6% |
| 반등 뒤 재하락 | +2.8% | -4.8% | -1.0% |
| 빠른 V자 회복 | +1.5% | +1.5% | +1.5% |

재매수 제한은 이 가상 경로들에서 사건 MDD를 추가로 낮추지 못했고, 세 경로에서 회복 수익을 더 많이 놓쳤다. 심화 방어 중 QQQ가 10% 아래로 내려갈 때만 사서 10% 근처로 돌리는 절충안은 일부 반등 손실을 줄였지만, 닷컴 대체검증 CAGR/MDD가 재매수 완전 제한 4.942%/-15.859%에서 **3.972%/-16.431%**로 나빠지고 거래도 27건에서 69건으로 늘었다. 따라서 이 10% 값도 채택하지 않는다. 닷컴 한 사례의 큰 개선만으로 재매수 제한을 30번에 확정하기에는 이르다.

## 빠른 동반 급락 경보의 시험과 비용

연구용으로 QQQ 5거래일 수익률 ≤ -12%, SPY ≤ -7%가 동시에 나타나면 QQQ 상한을 35%로 낮췄다. 두 자산이 EMA20 위이고 5일 수익률이 양수인 상태를 3거래일 확인하면 해제했다. 가상 동반 급락에서는 2024-01-05, 사건 시작 대비 약 **-13.3%** 손실 후 첫 발동했고 사건 MDD를 -39.3%에서 -25.0%로 낮췄다. 늦은 신용 경로에서도 약 -16.0% 손실 후 발동해 MDD를 -37.6%에서 -26.0%로 낮췄다. 갑작스러운 손실 자체를 없애지는 못한다.

| 과거 구간 | 기존 혼합안 CAGR / MDD | 급락 경보 추가 CAGR / MDD |
| --- | ---: | ---: |
| 2012~2026년 7월 | 21.188% / -16.253% | 20.742% / -16.323% |
| 닷컴 대체검증 | 2.892% / -23.100% | 2.969% / -22.766% |
| 금융위기 대체검증 | 11.692% / -26.745% | 10.635% / -26.745% |

급락 경보는 가상 손실을 크게 줄였지만 최근·금융위기 수익률을 낮췄고 해당 MDD 개선은 없었다. 이 단일 임계값 규칙은 30번 후보로 채택하지 않는다. 지난 시장 동반 급락 규칙 실험에서도 유사한 금융위기 수익률 비용이 나왔다.

## 판단

현재 가장 확실한 방어는 **장기 QQQ 주도 약세에서 두 단계 신호가 일찍 켜지는 경우**다. 신용 신호가 없거나 늦는 급락에서는 -38~-39% 가상 MDD가 나왔다. 재매수 제한은 이 문제를 해결하지 못했다. 즉 30번을 설계할 때 해결할 문제는 숫자 -10%나 20% 상한의 미세 조정보다, 신용 확인 전에 발생한 손실을 어떤 비용을 치르고 줄일지다. 가상 급락에 맞춘 규칙을 하나 더 넣으면 실제 구간 CAGR이 낮아졌으므로, 아직 30번 확정 규칙으로 추천할 수 없다.

이 경로들은 2024년 실제 상승장 가격에 결정적 배율을 곱한 스트레스 상황이다. 샘플의 빈도·시장 확률·다음 위기의 예상 낙폭으로 해석하지 않는다. 2024년의 기존 기술지표는 재계산했지만 밸류에이션과 현금 수익은 고정했고, 해외 ETF와 실제 연금 상품의 체결 차이도 포함하지 않았다. [연준의 스트레스 테스트 설명](https://www.federalreserve.gov/publications/2026-stress-test-scenarios.htm)처럼 가상 경로는 예측보다 취약점 파악에 쓰는 것이 적절하다.
