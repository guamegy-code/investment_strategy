# 28번 혼합안(21.182%) 후속 튜닝

검증일: 2026-09-26. 이 문서의 기준은 `REL10_CAP20_INDEPENDENT`: 28번 목표에 상대약세·신용악화 65% 상한과 심화 상대약세 20% 상한을 적용하고, 두 방어 단계를 독립적으로 해제하는 연구안이다. 금융주(XLF) 경보는 포함하지 않는다. 운영 전략 YAML과 배포 대상은 수정하지 않았다.

## 1. 신용 데이터 이용 시점

기존 연구는 FRED BAA10Y 관측일 값을 그날 종가 평가에 사용하고 다음 거래일 시가에 주문한다. 관측일 값이 당시 종가 평가 시점에 발표됐는지 확정되지 않으므로, 신용 시계열 전체를 QQQ 거래일 기준 1·2거래일 뒤로 옮긴 보수적 민감도를 계산했다. 이는 과거 시점별 실제 발표 기록을 재구성한 검증은 아니다. 예를 들어 [FRED BAA10Y](https://fred.stlouisfed.org/series/BAA10Y)는 관측일과 갱신일을 따로 표시한다.

| 신용 데이터 지연 | 최근 CAGR / MDD | 닷컴 대체검증 CAGR / MDD | 금융위기 대체검증 CAGR / MDD |
| --- | ---: | ---: | ---: |
| 0거래일, 기존 결과 | 21.182% / -16.253% | 2.916% / -22.998% | 11.692% / -26.745% |
| 1거래일 | 21.188% / -16.253% | 2.892% / -23.100% | 11.692% / -26.745% |
| 2거래일 | 21.186% / -16.253% | 2.645% / -24.168% | 11.692% / -26.745% |

## 2. 심화 방어 중 QQQ 재매수 제한

현행 연구안에서 20%는 고정 목표이기도 하다. QQQ 가격이 하락해 실제 비중이 목표보다 4%p 이상 낮아지면 다시 사서 20%로 맞출 수 있다. 대안은 심화 방어가 **이미 켜진 동안** 목표보다 낮아진 QQQ를 채우지 않는 것이다. 20% 초과분의 매도, 28번 기본 전략이 더 낮은 비중을 요구할 때의 매도, 심화 방어 해제 후의 복귀는 유지한다. 신규 심화 경보가 켜지는 날의 20% 축소도 그대로다. 현금성 자산은 BIL로 둔다.

| 1거래일 신용 지연 | 최근 CAGR / MDD | 닷컴 대체검증 CAGR / MDD | 금융위기 대체검증 CAGR / MDD | 닷컴 거래 |
| --- | ---: | ---: | ---: | ---: |
| 기존 20% 목표 유지 | 21.188% / -16.253% | 2.892% / -23.100% | 11.692% / -26.745% | 61건 |
| 심화 방어 중 재매수 제한 | 21.188% / -16.253% | **4.942% / -15.859%** | 11.692% / -26.745% | 27건 |

최근·금융위기 구간에는 심화 단계가 발동하지 않아 두 결과가 정확히 같다. 닷컴에서는 2000-04-03 심화 방어가 켜진 후 2003-05-28 해제되기까지 방어 중 추가 매수를 억제해 거래가 줄었다. `NoTopupDays=560`은 추가 매수를 억제한 **평가일 수**이며 주문 건수가 아니다. 닷컴 사건 구간(2000-03-27~2002-10-07)만 보면 기존 수익률/MDD -22.35%/-23.10%, 재매수 제한 -9.63%/-15.23%다.

재매수 제한의 닷컴 민감도:

| 조건 | 기존 CAGR / MDD | 재매수 제한 CAGR / MDD |
| --- | ---: | ---: |
| 신용 데이터 2거래일 지연 | 2.645% / -24.168% | 4.689% / -16.408% |
| 거래비용 3배 | 2.657% / -23.468% | 4.779% / -15.859% |
| BIL 대체수익 0% | 1.418% / -28.759% | 3.304% / -16.843% |

## 3. 심화 방어 부분 복귀

QQQ > EMA55, QQQ/SPY 20일 상대수익률 > 0, BAA10Y 20일 변화 ≤ 0, SPY > EMA55가 5거래일 이어지면 20% 상한을 35%로 올렸다. 이후 상대수익률 ≤ -5% 또는 신용스프레드 20일 확대 ≥ 0.30%p이면 다시 20%로 내렸다. 완전 해제는 기존 장기 회복 조건을 유지했다.

닷컴에서 이 조기 복귀는 여섯 번 발생하며 CAGR **2.363%**, MDD **-26.199%**, 거래 **85건**으로 기준보다 모두 나빠졌다. 2000-06-19에 첫 복귀한 뒤 2000-08-01 다시 방어로 돌아가는 등 하락 중 반등을 여러 번 따라갔다. 최근·금융위기는 심화 단계가 없어서 결과가 같다. 이 부분 복귀 규칙은 기각한다.

## 4. 첫 단계 상한 60%·65%·70%

다른 조건은 고정하고 첫 단계 QQQ 상한만 변경했다. 모두 신용 데이터 1거래일 지연이다.

| 첫 단계 상한 | 최근 CAGR / MDD | 닷컴 대체검증 CAGR / MDD | 금융위기 대체검증 CAGR / MDD |
| --- | ---: | ---: | ---: |
| 60% | 21.194% / -16.253% | 3.126% / -22.081% | 11.460% / -26.389% |
| 65% | 21.188% / -16.253% | 2.892% / -23.100% | 11.692% / -26.745% |
| 70% | 21.182% / -16.325% | 3.055% / -22.390% | 11.918% / -27.101% |

60%는 금융위기 MDD를 소폭 낮추지만 CAGR도 낮춘다. 70%는 반대다. 최근 구간의 차이는 약 0.01%p 수준이다. 60%와 재매수 제한을 결합해도 최근 21.194%/-16.253%, 닷컴 4.978%/-15.859%, 금융위기 11.460%/-26.389%로 60% 변경의 추가 이득이 작다. **65% 유지**가 간결하다.

## 판단과 한계

가장 유망한 변경은 심화 방어 중 재매수 제한이다. 닷컴 한 사례에서 CAGR·MDD·거래 수가 모두 개선됐고, 신용 지연·현금수익·비용 가정 변화에도 방향이 유지됐다. 그러나 2012년 이후와 금융위기에는 심화 단계가 한 번도 없으므로 이 규칙의 독립 사례는 아직 **한 건뿐**이다. 장기 하락 후 방어 해제 전에 강하게 반등하면 낮아진 QQQ 비중 때문에 수익을 놓칠 수 있다. 이 결과를 실제 투자 성과나 보장된 개선으로 해석해서는 안 된다.

### 2026-09-27 후속 판단: 30번 연구 우선 후보

현재 검증한 변경 중에서는 **기존 혼합안의 65%·20% 방어와 독립 해제는 유지하고, 심화 방어가 이미 켜져 있는 동안 QQQ 목표 비중까지의 추가 매수만 제한하는 안**이 가장 유망하다. 위 표의 4.942% / -15.859%는 이 전체 조합의 *닷컴 대체검증* CAGR/MDD다. 재매수 제한 단독 전략이나 실제 2000년 당시 투자 가능 성과를 뜻하지 않는다. 1거래일 늦춘 신용 관측, CAPE 대체 밸류에이션, 2007년 이전 합성 BIL 수익, 종가 평가·다음 거래일 시가 체결을 전제로 한다.

이 시점의 결론은 **연구 우선순위**이지 운영 승격 결정이 아니었다. [예상 밖 급락 경로 시험](strategy30-unknown-crash-stress.md)에서 신용 악화가 없거나 뒤늦게 나타나는 가상 급락의 MDD는 재매수 제한으로 개선되지 않았고, 일부 반등 경로에서는 사건 종료 수익률이 악화됐다. [두 단계 가격 경보 시험](strategy30-staged-shock-guard.md)은 가상 급락의 MDD를 낮췄지만 실제 과거 구간 수익률 손실이 컸다. 따라서 빠른 급락 취약점은 여전히 남는다. 후속 요청으로 30·31번 실행 YAML을 만들고 신용 데이터 공급을 연결한 내용은 [구현 검증 문서](strategy30-31-deployment-validation.md)에 분리해 기록했다. GitHub 반영은 별도 요청 전까지 보류한다.

닷컴 검증에는 S&P 500 CAPE로 대체한 밸류에이션 점수와 2007년 이전 합성 BIL 수익이 포함된다. 신용 시계열 지연은 발표 시각을 가정한 민감도이지 실제 빈티지 자료 검증이 아니다. 이 조건에서 30번을 만든다면 65%·20% 진입 및 기존 해제 조건을 유지하고, 심화 방어 중 재매수 제한만 추가하는 안을 우선 후보로 삼을 수 있다.
