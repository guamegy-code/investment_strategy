# QQQ 제한 재진입과 전환기 확인 속도 결합 검증

검토일: 2026-10-27. 대상: 개인연금 원천 30·32번의 QQQ/BIL 달러 계좌.

**제한 재진입에 회복 확인 가속만 결합하면 작은 추가 개선이 있다. 매도까지
가속하는 결합은 수익과 낙폭이 악화된다.**
기존 제한 재진입을 독립 버전 `REENTRY`, 회복 가속 결합을 `REENTRY_BUY`로
구분해 재현·비교한다. 이 문서의 결과는 연구 구현이며 운영 YAML·웹 배포와 구분한다.

후속 [고점 기억 보존·조기 매도 검증](qqq-memory-preserving-sell-review-2026-10-28.md)에서는
기존 밸류에이션 경로와 2020년 방어를 보존했지만 추가 수익에 실패했다.
회복 가속 결합 `REENTRY_BUY`를 비교 기준으로 유지한다.

## 결합의 범위

[방법 1의 제한 재진입](qqq-guarded-reentry-review-2026-10-27.md)은 강한 방어가
없고 가격 회복 조건을 충족할 때 잔여 현금의 절반을 추가 투입한다. 원래 목표
70%이면 85%, 80%이면 90%가 된다. 주간 첫 거래일 진입, 일별 조건 해제,
실제 변경 계좌를 원천 전략에 전달하는 구조를 그대로 사용했다.

방법 2의 이번 구현은 **단기·장기 추세가 엇갈릴 때 기존 상태 전이의 확인
기간을 줄이는 방식**이다. 이동평균 기간 자체를 매일 최적화하거나 모델을 학습하지 않는다.

- QQQ의 20·252거래일 수익률에서 같은 기간 BIL 수익률을 뺀 값을 계산한다.
- 단기 음수·장기 양수가 이틀 연속이면 하락 전환 신호, 반대이면 회복 전환 신호다.
- 매도 가속: 기존 BEAR 진입 확인 10→3일, WARNING→DEFENSE 확인 6→2일.
- 매수 가속: BEAR→RECOVERY와 CAUTION/RECOVERY→BULL 확인 3→1일.
- 해당 전환 신호가 없으면 원래 확인 기간을 사용한다. 원래 진입 조건과 우선순위는 유지한다.

기존 확인 후보가 누적한 날짜는 유지하며, 현재 종가에서 적용할 확인 일수를 정한다.
따라서 3→1일 변경은 달력상 항상 이틀 빠르다는 뜻이 아니다. 원래 조건이
사흘 연속 유지되지 않으면 두 전략의 실제 상태가 더 오래 달라질 수 있다.

신용·심화·금융 방어, 구조적 약세, 심화 방어 중 비중 재충전 금지 규칙을
변경하지 않았다. 밸류에이션 DEFENSE의 해제 확인도 그대로다. 다만 추세
BEAR를 더 일찍 해제하면 기존 QQQ 0% 대신 당시 신용 방어 상한 50%까지
투자할 수 있다. 방어 규칙 보존이 모든 날 같은 보유 위험을 뜻하지는 않는다.

빠른 추세와 느린 추세의 불일치를 전환 신호로 보는 아이디어는
[Breaking Bad Trends](https://people.duke.edu/~charvey/Research/Published_Papers/P167_Breaking_bad_trends.pdf)와
[저자의 연구 안내](https://people.duke.edu/~charvey/Teaching/663_2021/663_Syllabus.htm)를 참고했다.
해당 연구의 다자산 전략이나 수익률을 재현한 실험은 아니다. 기존의 고정
20/60/120일 계정 합산·연속형 앙상블과 달리 조건부 확인 속도의 증분을 측정한다.

## 설계와 실행

`validation/qqq_adaptive_speed_lock_20261027.json`에 첫 성과 계산 전에 규칙을 고정했다.
BASE·REENTRY·SPEED·COMBINED의 네 비교와, 매도/매수 분리 및 상시 가속
대조군까지 총 아홉 방식을 사전 정의했다. 숫자 문턱이나 기간을 탐색하지 않았다.

주요 비교 78개는 기본 세 기간×두 원천×아홉 방식 54개와, 현재 기간의
비용 3배·추가 1거래일 지연·둘의 동시 적용×두 원천×네 방식 24개다.
방향별 차이를 확인한 뒤 이미 정의된 REENTRY_SELL·REENTRY_BUY를 같은
세 스트레스로 12개 추가 검사했다. 후속 검사에서 전략 규칙을 바꾸지 않았고,
이 추가 범위는 `validation/qqq_adaptive_direction_stress_20261027.json`에 기록했다.

종가 판단·다음 시가 체결, 수수료 0.015%·슬리피지 0.020%를 매매 금액에
적용했다. 동일 대기 목표는 체결 기한을 유지하고 다른 새 목표는 대기 주문을
교체한다. 초기 투자는 기존 비교와 같이 지연 스트레스에서도 다음 시가다.
가격은 조정 OHLC, 수량은 소수점이며 실제 연금 ETF나 실계좌 호가 검증은 아니다.

## 전체 성과

2012-01-03~2026-07-31, 비용 차감 후. 이 기간의 30·32번 경로는 같다.

| 방식 | CAGR | MDD | 매매 발생일 |
|---|---:|---:|---:|
| 기존 BASE | 21.4189% | −16.2530% | 30 |
| 방법 1: 제한 재진입 REENTRY | 21.4997% | −16.2530% | 44 |
| 방법 2: 매도·매수 가속 SPEED | 20.2865% | −28.5593% | 31 |
| 방법 1 + 방법 2 전체 COMBINED | 20.3343% | −28.5593% | 37 |
| 매도 가속만 SELL_ONLY | 20.2699% | −28.5593% | 31 |
| 매수 가속만 BUY_ONLY | 21.4357% | −16.2530% | 30 |
| 방법 1 + 매도 가속 REENTRY_SELL | 20.3152% | −28.5593% | 39 |
| **방법 1 + 매수 가속 REENTRY_BUY** | **21.5190%** | **−16.2530%** | **42** |
| 전환 조건 없이 상시 양방향 가속 | 19.4771% | −28.5593% | 52 |

REENTRY_BUY의 추가 CAGR은 REENTRY 대비 **+0.0193%p**, BASE 대비
**+0.1001%p**다. 최종 자산은 각각 +0.232%·+1.209%이며 약 14년 반 전체의
차이다. 제한 재진입의 활성 기간은 79→74일, 진입은 7→6회로 줄었다.
가속된 추세 전이 10회가 전부 추가 매매를 뜻하지는 않는다. 다른 방어가
더 낮은 목표를 정하면 추세 상태가 바뀌어도 보유 목표는 같을 수 있다.

## 비용·지연과 채택 판단

| 조건 | REENTRY CAGR | REENTRY_BUY CAGR | 추가 개선 |
|---|---:|---:|---:|
| 기본 | 21.4997% | 21.5190% | +0.0193%p |
| 수수료·슬리피지 각각 3배 | 21.3226% | 21.3442% | +0.0216%p |
| 주문 추가 1거래일 지연 | 20.3845% | 20.5762% | +0.1917%p |
| 비용 3배와 지연 동시 적용 | 20.2189% | 20.4124% | +0.1935%p |

기본·비용·지연 각각의 전체 MDD는 두 방식이 같았다. 비용과 지연을 동시에
적용하면 −17.7035%에서 −17.6070%로 소폭 완화됐다. 지연 때 상대 개선이
더 크다는 사실은 일부 체결일의 차이이며 지연이 언제나 유리하다는 뜻이 아니다.
양쪽 전략 모두 기본 조건보다 절대 CAGR은 낮아졌다.

주요 결합 COMBINED는 추가 수익과 MDD 기준에 실패했다. 사전 정의된
방향별 조합 중 REENTRY_BUY는 REENTRY 대비 기본 CAGR 개선, 전체 MDD 악화
0.5%p 이내, 세 비용·지연 조건에서 개선 유지, 두 위기 MDD 악화 2%p 이내를
모두 충족했다. 방향별 스트레스는 기본 비교를 본 뒤 수행한 후속 검사다.

**REENTRY_BUY를 회복 가속을 접목한 별도 전략 버전으로 보존하고 후속 비교에
사용할 근거가 있다.** 큰 폭의 개선이나 미래 우위를 입증한 것은 아니다.
REENTRY와 BASE도 계속 대조군으로 유지하며, 운영 30·32번의 자동 교체·배포는
이번 연구 구현에 포함하지 않았다.

## 매도 가속이 더 큰 하락 노출을 만든 이유

밸류에이션 방어는 과거 고점을 기억하는 상태 규칙이다. 진입을 앞당기면
이후 해제 시점과 고점 재설정도 바뀌므로, 매도 시점만 국소적으로 바뀌지 않는다.

| 종가 판단일 | REENTRY | 매도 포함 COMBINED |
|---|---|---|
| 2019-10-08 | WARNING, 기억 고점 75.2063 | 조기 DEFENSE 진입, 같은 기억 고점 |
| 2019-10-11 | WARNING 유지, 고점 75.2063 | NORMAL 해제, 기억 고점 **49.1825로 재설정** |
| 2019-11-01 | WARNING 목표 QQQ 70% | NORMAL 목표 QQQ 100% |
| 2020-03-03 | DEFENSE 목표 QQQ 30% | NORMAL 목표 QQQ 100%, 기억 고점 69.2857 |

그 결과 COMBINED는 2020-02-19~03-16에 −28.5593%의 최대낙폭을 겪었다.
신용 방어 코드가 제거된 것이 아니라 밸류에이션 상태의 과거 경로가 달라졌다.
`qqq_adaptive_valuation_memory_trace.csv`에 기억 고점·상태·목표·실제 비중을 남겼다.
이 효과 때문에 매도 가속 결합을 채택하지 않는다.

## 회복 가속의 이익과 손실

REENTRY_BUY와 REENTRY의 연도별 상대 자산 배율 변화를 곱해 전체 차이와
일치하는지 검사했다. 다음 값은 CAGR 차이가 아니라 상대 자산 기여다.

| 연도 | REENTRY 대비 상대 자산 기여 | 주요 경로 |
|---|---:|---|
| 2019 | +0.8544% | 1월 28일 상승 추세 복귀로 QQQ 100% 진입을 앞당김 |
| 2022 | −0.6159% | 6월과 10월의 빠른 회복 진입으로 추가 하락 노출 |
| 2023 | −0.0013% | 앞선 보유 경로의 잔여 차이 |
| 나머지 | 사실상 0 | 최종 상대 자산에 실질 변화 없음 |

2022년 6월 8일 기존 전략은 BEAR·QQQ 0%였으나 후보는 RECOVERY로 바뀌어
신용 방어 상한인 50%를 목표로 했다. 이 목표 차이는 7월 19일까지 이어졌다.
따라서 회복 가속이 반등에서 항상 유리한 것은 아니다.

| 부분 기간 | REENTRY_BUY의 CAGR 차이 | MDD 차이 |
|---|---:|---:|
| 2012~2016 | 0 | 0 |
| 2017~2020 | +0.2779%p | 0 |
| 2021~2023 | −0.2446%p | **−0.5238%p** |
| 2024~2026-07 | 사실상 0 | 사실상 0 |

전체 MDD가 같다는 사실로 부분 기간의 위험 증가를 지우지 않는다. 개선의
집중도는 신뢰 수준과 작동 범위를 설명하며, 그 자체를 자동 기각 사유로 쓰지 않는다.

## 위기 대체 구간

| 원천·구간 | REENTRY CAGR / MDD | REENTRY_BUY CAGR / MDD |
|---|---:|---:|
| 30·32 / 닷컴 2000~2005 | 5.0605% / −15.8591% | 동일 |
| 30 / 금융위기 2007~2011 | 10.9936% / −25.5090% | 11.1270% / −25.0612% |
| 32 / 금융위기 2007~2011 | 12.3308% / −17.4447% | 12.4610% / −16.9662% |

닷컴에서는 가속된 상태 전이가 있어도 보호 목표가 우선해 자산 경로는 같다.
금융위기에서 30번의 목표 차이는 2008-03-25·08-07의 회복 진입에서 발생했다.
오래된 구간은 선행 연구의 지연 CAPE·합성 현금 자료를 사용한 스트레스다.
현재 기간과 같은 품질의 실제 장기 운용 기록이나 독립 미래 성과로 간주하지 않는다.

## 검증

- 본 비교 78개와 방향별 후속 스트레스 12개, 총 90개를 완료했다.
- BASE·REENTRY의 이전 실행기 대비 일별 계좌·매매 일치 24개를 확인했다.
- 기본 비교 54개의 미래 기간 절단 재실행, 원시 가격 특징의 절단 검사 6개를 통과했다.
- 신용·심화·금융·구조적 방어의 일별 상태가 모든 비교에서 원래 BASE와 같다.
  제한 재진입이 해당 보호 목표를 늘린 날도 없다. 추세·밸류에이션 경로는
  실험 대상으로 명시한 부분이며 이 동일성 주장에 포함하지 않는다.
- 관련 단위 검사 57개 통과. 새 검사 9개는 전환 증거 누적, 원래 조건 유지,
  결측·중립 신호의 확인 기간 복원, 보호 규칙, 실제 보유 피드백 등을 확인한다.
- 초기 상태 전이 로그에서 같은 목적지의 즉시 규칙을 가속으로 잘못 표시하던
  계수 오류를 수정하고 회귀 검사를 추가했다. 계좌·매매 규칙은 바꾸지 않았으며
  본 비교를 최종 코드로 다시 실행했다.
- 입력 해시 참조 184개와 출력 해시를 검증·저장했다.

## 한계와 재현

현재 기간과 위기 자료는 이미 여러 차례 살펴본 과거 데이터다. 부분 기간·미래
절단 검사는 작동 범위와 미래 정보 사용을 확인하며 새로운 독립 수익 검증을
만들지 않는다. 30·32번의 동일한 현재 결과를 독립 성공 사례 둘로 세지 않는다.
가격 계산에는 기존 무료 QQQ/BIL 일봉만 추가 사용하므로 새 유료 자료나 매일의
추론 모델이 필요 없다. 신용·밸류에이션 자료의 한계는 기존 전략에서 이어받는다.
