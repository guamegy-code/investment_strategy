# Buy 3 Dip 회복 지연 전략의 stage별 비중 탐색

## 목적

21번 `buy-3dip-bil-delayed-recovery`의 진입·회복 기준을 고정하고 stage 1~3의
QQQ 목표 비중만 다시 탐색했다. 기존 비중 `87% / 90% / 100%`는 대칭 회복 규칙이
아닌 회복 지연 규칙과 함께 재검증할 필요가 있었다.

## 검증 조건

- 기간: 2012-01-03~2026-08-14
- 진입: `-10% / -20% / -32.5%`
- 회복: `+7.5% / -8.5% / -17.5%`
- QQQ 비중 탐색: stage 1 `82~92%`, stage 2 `86~97%`, stage 3 `96~100%`
- 인접 stage 간 최소 2%p 차이와 단조 증가 제약
- 수수료 0.015%, 슬리피지 0.020%, 신호 다음 거래일 시가 체결

## 결과

| 구분 | stage 1 / 2 / 3 QQQ | CAGR | MDD | Calmar |
|---|---:|---:|---:|---:|
| 현재 21번 | 87% / 90% / 100% | 18.031% | -28.612% | **0.630** |
| CAGR 절충안 | 88% / 90% / 100% | **18.128%** | -28.810% | 0.629 |
| 공격형 | 90% / 92% / 100% | 18.375% | -29.574% | 0.621 |

현재 21번보다 CAGR과 MDD를 동시에 개선한 비중 후보는 없었다. 가장 보수적인
CAGR 개선 후보인 `88% / 90% / 100%`는 CAGR을 0.096%p 높이는 대신 MDD를
0.198%p 악화시키고 Calmar를 0.001 낮췄다. 실제 DSL 엔진에서도 CAGR 18.128%,
MDD -28.810%, Calmar 0.629로 재현됐다.

## 결론

위험조정 성과를 우선하는 현재 21번의 비중은 유지한다. CAGR만을 조금 더 우선할
경우 `88% / 90% / 100%`를 별도 후보로 사용할 수 있지만, 현 시점에서는 전략
정의나 Cloudflare 배포를 변경하지 않는다.
