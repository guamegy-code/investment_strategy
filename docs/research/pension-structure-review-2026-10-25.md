# 개인연금 전략의 규칙 제거와 독립 추세 운용

검토일: 2026-10-25. **후속 검토 기준을 모두 통과한 새 후보는 없다.**
즉시 구조적 약세 방어를 제거하면 전체 수익률은 조금 높아졌지만, 개선이 짧은 한 사건에
집중됐고 주문 지연에서 우위가 사라졌다. 20·60·120일 독립 추세 두 후보도 기준에 미달했다.

이번 검토는 구조 교체 연구의 첫 단계인 규칙 제거와 독립 추세 운용을 다룬다.
방어 자금의 자산 선택과 실제 국내 상품의 원화 방어는 이번 결과에 포함하지 않았다.
추가 방어 규칙의 선행 결과는 [앞선 개인연금 검증](pension-downside-backtest-2026-10-25.md)에 있다.

## 설계와 비교 기준

실행 전에 `validation/pension_structure_lock_20261025.json`에 후보·기간·비용·판정을 고정했다.
이 자료는 이전 연구에서 이미 여러 번 살펴본 과거 이력이다. 이번 잠금은 현재 실험의
사후 변경을 막기 위한 것으로, 과거 전체를 독립 검증 구간으로 만드는 것은 아니다.

| 구분 | 설계 |
| --- | --- |
| 기준 | 실제 30번·32번 YAML. 규칙 제거는 30번을 기준으로 하나씩 적용 |
| 자산 | QQQ와 BIL, 공매도·레버리지 없음 |
| 주요 기간 | 2012-01-03~2026-07-31, 3,665거래일 |
| 위기 대체 기간 | 닷컴: 2000-03-10~2005-12-30, 금융위기: 2007-01-03~2011-12-30 |
| 판단·실행 | 종가 판단, 다음 거래일 시가 매매 |
| 기본 비용 | 매매 금액당 수수료 0.015%+슬리피지 0.020% |
| 신용 지표 | BAA10Y 1거래일 지연. 신용 방어를 제거한 경우에도 동일 입력 자료 사용 |
| 비교 달력 | 각 기간 기준 전략의 가용 거래일을 모든 후보에 공통 적용 |
| 후속 검사 | 비용 3배, 주문 추가 1거래일 지연, 미국 자산의 원화 환산 |

역사적 후속 후보의 기준은 실행 전에 다음과 같이 정했다. 이는 운영 배포 기준이나
확정된 손실 허용 한도가 아니라 이번 비교의 선별 조건이다.

- 주요 기간 CAGR이 30번보다 높고 전체 MDD 악화가 0.5%p 이내일 것.
- 2012~2016·2017~2020·2021~2023·2024~2026의 네 구간 중 두 구간 이상에서 CAGR이 높을 것.
- 두 위기 대체 기간에서 MDD 악화가 각각 2%p 이내일 것.
- 비용 3배·주문 지연·원화 환산에서도 CAGR 개선이 남을 것.

## 제거한 규칙

각 제거는 해당 상태의 초기값을 고정하고 갱신 규칙을 비웠다. 나머지 상태·목표 우선순위·
리밸런싱 조건·숫자 문턱은 원본 그대로 유지했다. 따라서 다른 목표 규칙이 제거한 상태를
다시 활성화하지 않는다. 제거된 상태가 모든 거래일에 고정돼 있는지도 확인했다.

| 후보 | 제거한 기능 |
| --- | --- |
| DROP_VALUATION | 밸류에이션 WARNING·DEFENSE를 비활성화 |
| DROP_DIP_BUY | 하락 매수 단계를 0으로 고정. WARNING 중 가격 하락을 이유로 100%를 복원하는 동작 제거 |
| DROP_CREDIT | 신용 경보·심화 방어를 함께 비활성화. 해당 방어에서의 비중 재충전 금지도 작동하지 않음 |
| DROP_STRUCTURAL | 구조적 약세 조건을 즉시 반영하는 QQQ 50% 상한만 비활성화. 10일 확인 후 BEAR 진입은 유지 |
| DROP_TREND | 위 즉시 방어와 BEAR·RECOVERY 목표를 함께 비활성화. 밸류에이션·신용 방어는 유지 |

이 결과는 현재 다른 규칙들이 존재할 때의 **조건부 기여**다. 개별 차이를 단순히 합해서
전체 전략 수익률의 원인으로 나눌 수는 없다. BASE32와 BASE30의 차이는 금융주 조건부
방어의 기존 비교 기준으로 함께 기록했다.

## 독립 추세 운용

두 후보 모두 시작 자금을 20·60·120거래일의 세 계정에 각각 1/3씩 배정한다.
계정 사이의 자금은 이후 재분배하지 않는다. 수익률에 따라 계정의 자본 비중이 달라진다.

- **SMA_SLEEVES:** 각 계정은 QQQ 종가가 자기 기간의 단순 이동평균보다 높으면 QQQ,
  그렇지 않으면 BIL을 보유한다.
- **EXCESS_SLEEVES:** 각 계정은 자기 기간의 QQQ 총수익률이 BIL 총수익률보다 높으면
  QQQ, 그렇지 않으면 BIL을 보유한다.

신호가 바뀔 때만 해당 계정이 매매한다. 세 계정의 자산가치를 합산했으며, 매일 동일 비중으로
섞은 수익률을 사용하지 않았다. 거래 비용도 계정별 실제 매매 금액에서 차감했다. 계정 간
반대 주문의 상계에 따른 비용 절감은 가정하지 않았다. 계정별 거래 횟수 합계와 실제 매매가
발생한 날짜 수를 따로 기록했다.

추세 연구의 참고 문헌은 [Moskowitz·Ooi·Pedersen의 원문 소개](https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum)다.
해당 연구는 여러 선물·선도 시장의 주로 12개월 신호를 다룬다. 이번 단일 자산·짧은 기간
설계는 별도의 가설이며, 문헌의 성과를 재현했다고 주장하지 않는다.

## 단순화 후보의 작은 개선을 채택하지 않은 이유

DROP_STRUCTURAL의 주요 기간 CAGR은 **+0.063%p**, 전체 MDD는 같았고 매매일은
30일에서 28일로 줄었다. 그러나 QQQ 목표가 기준과 달랐던 날은 **2016-02-03~02-16의
9거래일**뿐이었다. 기준의 50% 대신 100%를 유지한 구간이다. 실제 상대 수익 경로의 변화는
다음 시가 체결 이후인 2월 4~18일에 발생했다.

| 검사 | 기준 CAGR | 단순화 CAGR | 차이 |
| --- | ---: | ---: | ---: |
| 기본 달러 | 21.419% | 21.482% | +0.063%p |
| 비용 3배 | 21.264% | 21.339% | +0.075%p |
| 주문 추가 1일 지연 | 20.298% | 20.286% | **-0.013%p** |
| 미국 자산 원화 환산 | 23.231% | 23.295% | +0.064%p |

2012~2016 CAGR은 +0.177%p였으나 나머지 세 구간의 개선은 사실상 0이었다. 네 구간 중
두 구간 이상 개선 조건에 미달한다. 더욱이 2015년 7월~2016년 4월 사건의 MDD는
**-13.918%에서 -16.104%로 악화**됐다. 전체 MDD가 같다는 수치만 보면 이 위험 증가가 가려진다.

즉시 구조적 약세 방어가 늘 이롭다는 결론도, 없애면 안정적으로 수익이 높아진다는 결론도
내리지 않는다. 현재의 작은 개선은 반복성과 실행 안정성이 부족해 운영 변경 후보로 올리지 않는다.

## 후속 검사와 최종 판단

현재 CAGR·MDD의 1차 조건을 통과한 DROP_STRUCTURAL과 독립 운용 중 CAGR이 높은
EXCESS_SLEEVES에 비용·지연·원화 검사를 실행했다. EXCESS_SLEEVES는 탈락 원인을
확인하는 진단용이며, 수익률 기준을 통과한 후보로 취급하지 않았다.

| 조건 | 독립 모멘텀 CAGR / MDD | 같은 조건의 30번 CAGR / MDD |
| --- | ---: | ---: |
| 비용 3배 | 11.204% / -20.433% | 21.264% / -16.338% |
| 주문 추가 1일 지연 | 13.143% / -18.984% | 20.298% / -17.524% |
| 원화 환산 | 14.580% / -17.452% | 23.231% / -16.303% |

추가 주문 지연은 선행 연구에서 보완한 `StableDelayBacktest`를 사용했다. 동일 대기 주문의
기한을 반복해서 초기화하지 않으며, 다른 목표의 새 신호는 대기 주문을 교체한다. 이번에는
신용 지표 지연을 1일로 유지하고 주문 지연만 변경했다. 앞선 자료 지연+주문 지연 실험과
수치를 혼동하지 않는다.

원화 표는 미국 QQQ/BIL을 원화로 환산한 참고 모형이며 공통 거래일은 3,659일이다.
국내 머니마켓 ETF로 방어할 때의 환노출 변화나 실제 30P 상품 성과를 재현한 것이 아니다.

7개 신규 후보 중 사전 후속 기준을 모두 통과한 후보는 없다. 핵심 규칙을 유지하는 근거와
단순화의 작은 가능성은 확인했지만 새 운영 전략을 만들 근거는 확보하지 못했다.
다음 연구 대상은 방어 자금의 자산 선택과 실제 원화 방어다. 이번 실행에서는 검증하지 않았다.

반복 탐색에 따른 과적합은 [Bailey 등의 연구](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)가
다루는 문제다. 이번에는 후보 수와 탈락 결과를 함께 남겼으며, 결과를 본 뒤 새 문턱을
추가해 과거 수치를 끌어올리는 탐색은 수행하지 않았다.
