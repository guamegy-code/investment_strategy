# 개인연금 30·32번: 단기 급락 방어와 재진입 검증

검토일: 2026-10-25. **이번 후보는 채택하지 않는다.** 추가 방어는 일부 사건의
낙폭을 줄였지만, 거래 비용 차감 후 전체 연복리 수익률을 개선하지 못했다.
30·32번의 기존 신호와 목표 비중을 기준으로 비교했으며 31번은 포함하지 않았다.

## 검증 범위

- 기간: 2012-01-03~2026-07-31, 미국 거래일 3,665개. 기존 연구와 같은 가격·밸류에이션
  자료를 사용했다. 새 공개 지표의 10월 자료가 있어도 기준 전략 입력을 임의로 연장하지 않았다.
- 기존 YAML을 메모리에서 읽어 추가 방어를 적용했다. 추가 규칙이 요구하는 QQQ 비중보다
  기존 목표가 낮으면 기존 목표가 우선한다. 심화 방어 중 비중 재충전 금지도 유지했다.
- 종가 판단, 다음 미국 거래일 시가 매매. 거래 금액당 수수료 0.015%와 슬리피지 0.020%를
  적용했다. 비용 3배와 자료 2거래일 지연·다음다음 시가 매매도 별도로 비교했다.
- Cboe 지표와 BAA10Y는 기본 1거래일 지연했다. 거래량과 가격은 당일 종가 자료다.
  과거 수정 전 원자료를 모두 확보한 완전한 point-in-time 검증은 아니다.
- 새 지표에 결측이 있으면 신규 경보를 만들지 않는다. 활성 방어는 유지하고 해제 확인을
  다시 시작한다. 결측을 정상 지표값으로 바꾸지 않았다.
- 30·32번은 이번 기간에서 기준 및 최초 7개 비교군의 **일별 자산 경로까지 동일**했다.
  이는 32번의 금융위기 대응 효과를 부정하는 결과가 아니다. 이번 새 지표 조합은 VIX9D
  이력 제약으로 2008년을 직접 검증하지 않았다.

## 비교한 규칙

진입 가격 조건은 QQQ 5거래일 수익률 -3% 미만이다. 초기 QQQ 상한은 80%다.
기존 목표가 이미 80% 이하면 새 규칙의 비중 축소 효과는 없다.

| 코드 | 추가 조건과 복귀 방식 |
| --- | --- |
| BASE | 기존 YAML 그대로 |
| PRICE_SLOW | 가격 조건으로 진입. 종가>EMA20 및 5일 수익률>0이 3일 연속이면 해제 |
| TERM_SLOW | 가격 조건과 VIX9D/VIX>1.05, VIX/VIX3M>1을 함께 확인. 해제는 PRICE_SLOW와 동일 |
| TERM_VVIX_SLOW | TERM_SLOW에 VVIX의 과거 252일 80분위 초과·5일 상승률>10%·QQQ<EMA20 확인 추가 |
| TERM_FAST | TERM_SLOW 진입. 가격 회복과 두 변동성 비율 정상화를 확인한 첫날 90%, 이틀째 상한 해제 |
| TERM_VOLUME_FAST | TERM_FAST에 최근 5일 하락일 거래량 비중>65% 추가 |
| TERM_MEMORY_FAST | TERM_FAST 해제 후 20거래일 내 재진입하고 QQQ<EMA200·EMA200 하락이면 상한 65% |
| TERM_PRICE_FAST | TERM_FAST에서 변동성 정상화 대기를 제거하고 가격 회복으로만 90%→상한 해제 |

TERM_PRICE_FAST는 최초 결과를 본 뒤 해제 지연의 원인을 분리하려고 추가한 후속 실험이다.
독립 검증으로 취급하지 않는다. 이름의 FAST는 2단계 복귀 설계를 뜻하며 실제 방어 기간이
항상 짧다는 뜻은 아니다. 회복 첫날 이후 조건이 깨지면 초기 상한으로 돌아간다.

자산가치로 나눈 값이며 최초 투자도 포함한다. 보통의 편도 회전율과 직접 비교하지 않는다.

VVIX 원자료에는 **2013-05-13이 빠져 있다**. 완전한 252개 관측을 요구하는 분위수 계산에
이 결측이 전파되어, 2013-05-14~2014-05-14의 253거래일 동안 해당 후보의 신규 경보 계산을
보류했다. 이 결과를 결측 없는 VVIX 전략 성과로 해석해서는 안 된다. 다른 표의 후보에는
이번 기간 중 필요한 입력의 결측일이 없었다. 공개 일별 자료의 존재와 과거 전체의 완전성은 별개다.

## 개선되지 않은 이유

**가격만 보고 자주 방어하는 방식의 반등 손실이 컸다.** 기간구조를 추가하면
리밸런싱은 146회에서 62회로 줄고 수익률은 올라갔지만, 기존 전략보다 여전히 낮았다.

**변동성 정상화 대기가 빠른 복귀를 보장하지 않았다.** TERM_SLOW의 활성 기간은
391일, TERM_FAST는 416일이었다. 가격만 확인하는 2단계 복귀는 333일로 줄였으나
수익률 20.396%로 기존 21.419%에 못 미쳤고 MDD 개선도 0.140%p에 그쳤다.

**특정 하락의 이익이 다른 사건의 손실을 상쇄하지 못했다.** 아래는 TERM_FAST와
기준 전략의 동일 사건 구간 비교다. 회복 기간은 기준 전략의 해당 구간 저점부터
각 전략이 사건 시작일 자산가치를 회복하기까지의 거래일이다. 전체 고점 회복 기간과 다르다.

| 사건 | 기존 MDD → 후보 MDD | 기존 회복 → 후보 회복 |
| --- | ---: | ---: |
| 2015~2016 | -13.918% → -15.556% | 관측 창 안에 양쪽 모두 회복 못함 |
| 2018년 4분기~2019년 4월 | -14.508% → -13.605% | 92일 → 81일 |
| 코로나~2020년 8월 | -11.187% → -12.373% | 23일 → 37일 |
| 2020년 9~12월 | -12.749% → -12.749% | 48일 → 52일 |
| 2021년 11월~2023년 말 | -14.559% → -14.559% | 133일 → 133일 |
| 2025년 2~10월 | -16.253% → -15.146% | 52일 → 52일 |

2022년 사건 구간에는 추가 비중 축소의 실질 효과가 없었다. 장기 하락 재진입 기억도
이번 진입 조건과 결합하면 결과가 같았다. 기억 규칙 자체가 항상 무효라는 뜻이 아니라,
이 조합으로는 장기 하락 대응을 개선하지 못했다는 뜻이다.

**단순히 평균 위험 비중을 조금 낮춘 것보다 수익률 손실이 컸다.** TERM_FAST의 평균
QQQ 목표 90.682%에 맞추어 기존 목표를 일정 배율로 줄인 대조군은 CAGR 21.184%,
MDD -16.103%, 리밸런싱 29회였다. 후보는 같은 평균 목표에서 CAGR 20.271%였다.
대조군 배율은 전체 결과를 본 뒤 계산한 귀속 분석용 값이며 투자 가능한 독립 전략이 아니다.
실제 평균 보유 비중은 대조군 90.964%, 후보 90.679%로 정확히 일치하지 않는다.

기간별 분할에서도 TERM_FAST는 2012~2016·2017~2020·2024~2026에 기준 수익률보다
낮았고 2021~2023에는 같았다. VVIX 후보의 2024~2026 CAGR은 23.846%로 기준 23.746%보다
조금 높았으나 전체 결과를 뒤집지는 못했다. 이 분할은 과거 구간별 설명이며 워크포워드가 아니다.

## 비용·지연·원화 확인

30번 기준이다. 각 열은 해당 실험의 동일 조건 기준 전략과 비교해야 한다.

| 조건 | 기존 CAGR / MDD | 기간구조 | 기간구조+VVIX | 기간구조+단계 복귀 |
| --- | --- | --- | --- | --- |
| 비용 3배 | 21.264% / -16.338% | 20.110% / -15.725% | 20.407% / -15.406% | 20.051% / -15.837% |
| 자료 2일 지연+다음다음 시가 | 20.321% / -17.524% | 19.734% / -17.145% | 19.747% / -17.524% | 19.532% / -17.656% |
| 달러 자산 원화 환산 | 23.231% / -16.303% | 22.112% / -16.303% | 22.396% / -16.303% | 22.066% / -16.303% |

지연 검증 중 기존 엔진이 같은 대기 주문도 새 주문처럼 교체하여 실행 날짜를 계속
늦추는 문제가 확인됐다. 최초 `pension_downside_delay_*` 결과는 **폐기 대상이며 결론에서
제외**했다. 연구용 `StableDelayBacktest`가 동일 목표·동일 분할일의 주문 기한을 유지하도록
보완한 `pension_downside_delay_corrected_*`만 위 표에 사용했다. 다른 목표의 새 주문은
기존 엔진과 같이 교체한다. 이 보완은 연구 스크립트 안에만 있고 운영 엔진에는 적용하지 않았다.
단위 검사로 동일 주문이 원래 예정된 두 번째 시가에 실행되는지 확인했다.

자료 지연과 주문 지연은 이 스트레스에서 함께 변경했다. 두 요인의 기여를 분리한 결과가 아니다.
원화 환산은 기존 엔진의 FX 공통일 3,659개를 사용한다. 같은 조건 안에서 후보를 비교했으며,
미국 거래일 3,665개의 달러 표와 완전히 같은 달력은 아니다.

## 실제 개인연금 상품에 적용할 때 남는 한계

원화 표는 **미국 QQQ/BIL을 원화로 평가한 참고 모형**이다. 국내 ETF의 실제 실행 수익률이 아니다.
특히 BIL도 달러 자산이므로 국내 원화 머니마켓 ETF로 이동할 때의 환노출 변화는 재현하지 않는다.

30P는 QQQ 배분을 KODEX 미국나스닥100(379810)과 KoAct 미국나스닥성장기업액티브(0015B0)에
절반씩 나누며 방어 자산은 KODEX 머니마켓액티브(488770)다. 현재 캐시는 379810이
2021-04-09부터, 0015B0은 2025-02-25부터다. 488770 캐시는 없다. 이 짧은 실제 상품 이력으로
2012년부터의 연금 성과를 만들거나, 32P 매핑이 이미 존재한다고 가정하지 않았다.

후보가 기준 수익률을 넘지 못해 국내 상품 적용·배포 단계로 진행하지 않았다. 채택 후보가
생기면 국내 상품 공통 기간, 한국·미국 휴장일, 시차, 괴리율·스프레드, 실제 원화 방어 자산을
사용해 다시 검증해야 한다. 30번과 32번 중 어느 것을 운영 기준으로 선택할지는 이번
2012년 이후의 동일 결과만으로 새로 결정하지 않는다.

차익·비차익 프로그램매매는 이번 백테스트에 포함하지 않았다. 국내 수급과 미국 기초자산
전략의 연결 근거 및 실제 API 조회가 아직 부족하다. 데이터 조사 결과는
[선행 지표 검토](downside-response-signal-review-2026-10-25.md)를 참고한다.

## 판단과 다음 연구

7개 신규 조합은 현 설정으로 채택하지 않는다. 결과를 개선하려고 문턱을 넓게 탐색하지 않았다.
기본 비교 실패 후 비용 2배·상한 및 가격 문턱 주변의 전체 격자는 실행하지 않았으며,
비용 3배와 지연 스트레스로 실패가 뒤집히는지만 확인했다.

다음 연구의 우선순위는 다음 두 가지다.

1. 이미 강한 방어에 들어간 뒤의 복귀 시점을 개선한다. 새 매도 신호를 더해 발생한
   손실과 기존 방어가 늦게 풀려 발생한 손실을 구분하고, 동일 진입·해제만 변경해 비교한다.
2. 2022년처럼 급락 경보가 드문 장기 하락에는 기간구조를 필수 진입 조건으로 두지 않은
   별도 가설을 만든다. 가격·거래량·재진입 실패의 기여를 하나씩 분리한다.

후속 가설의 성과는 아직 계산하지 않았다. 과거 연구에 반복 노출된 기간이므로 신규 규칙이
나와도 독립 검증 성과라고 부르지 않는다.

코드: `src/legacy-python/validation/pension_downside_review.py`.
