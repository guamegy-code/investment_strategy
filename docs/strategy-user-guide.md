# 전략 사용자용 전략 검토 및 알림 설정 안내

이 문서는 전략을 검토·수정하고 본인에게 Telegram 알림을 받는 전략 사용자를 위한 안내입니다.
Cloudflare, 데이터 저장소, 배포 설정은 다루지 않습니다.

## 준비물

- 전략 웹페이지 주소
- Google 계정
- Telegram 봇과 본인 채팅 ID
- 운영자가 전달한 평가 API 주소와 API 키

평가 API 키는 운영자에게 별도로 문의해 받으세요. 키를 스프레드시트 셀, YAML 파일,
Git 저장소, 채팅에 기록하거나 공유하면 안 됩니다.

## 1. 웹페이지에서 전략 검토

1. 운영자가 전달한 전략 웹페이지를 엽니다.
2. 기본 전략을 선택해 성과, 낙폭, 비중 변화를 검토합니다.
3. 수정할 전략이 있으면 YAML 파일을 준비합니다.
4. 웹페이지의 **전략 가져오기**를 선택해 YAML 파일을 불러옵니다.

가져온 YAML은 해당 브라우저에만 저장됩니다. 다른 사람에게 자동 공유되거나 공개 전략
목록에 반영되지 않습니다.

## 2. 알림용 스프레드시트 준비

1. 새 Google 스프레드시트를 만들고 Apps Script를 엽니다.
2. 운영자가 제공한 `Code.gs` 전체를 붙여 넣고 저장합니다.
3. Apps Script의 **프로젝트 설정 → 스크립트 속성**에 아래 값을 입력합니다.

```text
EVALUATION_API_URL=운영자가 전달한 주소
EVALUATION_API_KEY=운영자에게 문의해 받은 키
TELEGRAM_BOT_TOKEN=본인 Telegram 봇 토큰
TELEGRAM_CHAT_ID=본인 채팅 ID
SPREADSHEET_ID=현재 스프레드시트 ID
```

`SPREADSHEET_ID`는 스프레드시트 주소에서 `/d/`와 `/edit` 사이의 문자열입니다.

4. `setupSpreadsheet()`를 한 번 실행합니다.
5. Telegram에서 봇과 대화를 열어 `/start`를 보낸 뒤 `sendTestMessage()`를 실행합니다.

## 3. 전략 등록과 초기화

### 기본 전략 알림

`알림 전략` 탭에서 다음을 입력합니다.

- `알림`: 체크
- `전략 ID`: 웹페이지에서 검토한 전략 ID
- `전략명`: 선택 입력

### 개인 전략 알림

개인 YAML은 공개 웹사이트에 올리지 않습니다.

1. `개인 전략` 탭 A열에 YAML의 `strategy.id` 값을 입력합니다.
2. 같은 행 B열에 YAML 파일 전체 내용을 붙여 넣습니다.
3. `알림 전략` 탭에도 같은 전략 ID를 넣고 `알림`을 체크합니다.

전략을 등록하거나 YAML을 수정한 뒤에는 `initializeNotificationStates()`를 실행합니다.
여러 전략을 체크해도 순차적으로 초기화됩니다.

## 4. 자동 알림 시작

`installTriggers()`를 한 번 실행합니다. 이후 매일 KST 07:00~10:00에 전략을 평가합니다.
토요일에는 직전 미국 거래일 기준 주간 시장 브리핑을 보내고, 평일에는 아래 선별 사건이
있을 때만 Telegram 메시지를 보냅니다.

- `리밸런싱 실행`: 실제 주문이 필요한 목표 비중과 현재 대비 증감
- `사전주의`: DEFENSE·BEAR·RECOVERY 관련 상태 변화나 확인 시작, 목표 괴리 5%p 최초 돌파
- `주간 시장 브리핑`: 추세·밸류에이션 상태, QQQ 1·5·20일 변화, 약세·회복 점수와 현재 비중

같은 시장 기준일에 주간 브리핑과 사건 알림이 겹치면 한 메시지로 합칩니다. 목표 비중 괴리
경고는 4%p 아래로 내려간 뒤 다시 5%p를 넘을 때만 재발송합니다. 목표가 바뀌지 않는
일반적인 BULL↔CAUTION 변화는 즉시 발송하지 않고 다음 주간 브리핑에 표시합니다.

확인은 다음 탭에서 합니다.

- `실행 로그`: 평가 성공·실패, 발송 건수
- `알림 이력`: 발송된 실행·사전주의·주간 메시지와 같은 날 합쳐진 기록

### 실제 상품 연결 전략

`source`와 `products`를 사용하는 상품연결 전략도 기준 전략의 상태와 신호를 그대로 사용합니다.
알림의 현재·목표·증감 비중은 QQQ 같은 기준 자산이 아니라 실제 상품 코드로 표시됩니다.
상품연결 전략은 별도의 전략 ID이므로 `알림 전략` 탭에서 그 ID를 구독해야 합니다. 같은 계좌를
두고 원본 전략과 상품연결 전략을 동시에 구독하면 동일한 신호가 두 번 올 수 있으므로 실제 운용
전략 하나만 선택하세요.

## 주의 사항

- API 키와 Telegram 봇 토큰은 본인 Apps Script의 스크립트 속성에만 보관합니다.
- 개인 전략 YAML은 본인이 접근 권한을 가진 스프레드시트에만 넣습니다.
- 전략 ID는 영문·숫자·하이픈 조합의 고유한 값으로 만듭니다.
- 오류가 발생하면 `실행 로그`와 Apps Script의 **실행** 화면의 오류 메시지를 운영자에게 전달합니다.
