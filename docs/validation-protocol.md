# 전략 비교 검증 기준

## 일반 전략 비교

일반적인 전략 간 상대 성과 비교는 다음 기준을 사용합니다.

- 기준 시작일: `2012-01-03`
- 시작일보다 앞선 이력이 있어도 비교 성과는 기준 시작일부터 계산
- 종료일이 다르면 비교 대상들이 모두 보유한 가장 이른 종료일로 통일
- 모든 비교 행은 같은 시작일, 종료일과 관측치 수를 사용
- 기본 거래비용을 포함

생산 전략 실행과 원시 데이터는 더 긴 이력을 보존할 수 있습니다. 이 규칙은
"어느 전략이 더 나은가"를 판단하는 일반 비교 보고서에만 적용합니다.

일반 비교 결과는 `results/general_strategy_comparison.csv`에 기록합니다.

## 예외 검증

다음 검증은 자체 기간을 유지합니다.

- 필수 상품이나 외부 지표가 2012-01-03 이후에 시작하는 검증
- 워크포워드 및 고정 전방 OOS 검증
- 장기 프록시와 위기 구간을 사용하는 확장 스트레스 검증
- 특정 사건 또는 상품 상장 이후만을 대상으로 하는 검증

일반 전략 중 필수 데이터가 늦게 시작하는 전략은 일반 비교표에서 제외하고
`results/general_strategy_comparison_exceptions.csv`에 실제 시작일과 제외 사유를
기록합니다. 예외 전략끼리 비교할 때에는 별도의 공통 가용 구간을 사용해야 합니다.

## 기간 분할과 롤링

- 개발 구간: 2012-01-03~2020-12-31
- 최근 구간: 2021-01-01 이후
- 롤링 검증: 완결된 3년 또는 5년 달력 구간만 사용
- 불완전한 마지막 롤링 구간은 포함하지 않음
